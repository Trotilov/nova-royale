# NOVA ROYALE v0.1

Независимый Android-трекер для ручного отслеживания карт в Null's Royale. Сборка специально задумана для горизонтального экрана Xiaomi Pad 6.

## Уже реализовано

- Плавающая круглая кнопка **NR** поверх игры, которую можно перетаскивать.
- Раскрываемая панель с 8 слотами обнаруженных карт соперника.
- Каталог распространённых карт с ценой в эликсире и поиском.
- Возможность добавить собственную карту и её стоимость.
- При выборе сыгранной противником карты запоминается колода и списывается предполагаемая стоимость.
- Примерный эликсир соперника с ручной корректировкой **−1 / +1** и переключением **×1 / ×2 / ×3**.
- Последние четыре сыгранные карты, сброс для нового боя.
- Сохранение данных между открытиями панели и перезапусками приложения.
- Работа без интернета, доступа к файлам игры, Accessibility, root и инъекций.

**Не реализовано:** автоматическое распознавание экрана, скрытая колода, автоигра, работа с игровым процессом. Эликсир — только приблизительная оценка, а не доступ к серверному состоянию.

## Как скачать APK без компьютера

1. Откройте GitHub → **Actions** → **NOVA ROYALE APK**.
2. Откройте успешный запуск workflow для ветки `main`.
3. В разделе **Artifacts** скачайте `NOVA-ROYALE-v0.1-debug-apk`.
4. На планшете распакуйте ZIP, установите `app-debug.apk`.
5. Откройте NOVA ROYALE → разрешите **показ поверх других окон** → нажмите **Запустить панель**.
6. Перейдите в Null's Royale, переместите кнопку **NR**, откройте панель и выбирайте карты **после** их появления в бою.

Если на MIUI/HyperOS панель исчезает после перехода в игру, проверьте разрешения на всплывающие окна и фоновую работу приложения.

## Важно

NOVA ROYALE не является частью Null's Royale или Clash Royale. Условия использования частного сервера могут ограничивать игровые помощники; наличие отдельного приложения не означает автоматического разрешения на его применение в публичных матчах.
